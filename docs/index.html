Production Claude / MCP workflow

MegaMCP: AI proposes, a human approves, every change can be undone

A 2-minute walkthrough recorded against a sandbox ad account on a local build of the production codebase. Claude calls the MCP tools, reads run instantly, and writes come back as plans with diffs. A person approves in the dashboard, undo is itself a plan, and the flight recorder logs everything.

TriggerA user asks Claude, or a scheduled workflow runs
Tools170+ MCP tools across Google Ads, Meta, Microsoft Ads, GA4, Search Console, Tag Manager, WordPress and HubSpot
SafetyOAuth 2.1, AES-256-GCM vault, budget caps checked twice, drift refusal, untrusted-data instructions
RecordEvery read, plan, approval, apply and undo, with who and which AI client

Source for a minimal open reference implementation of the pattern: github.com/qcwebworks/approval-gated-mcp. Product: megamcp.com.
